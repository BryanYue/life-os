**已完成**限定于所列本地能力；**部分**表示最终门槛仍有明确边界；**阻塞**表示需不可用或未批准的外部条件。完整原始范围未删减，实际命令与失败修复见 [validation.md](validation.md)。所有验证只用虚构数据，不读取真实 Vault，不做金融执行。

## 交付和剩余条件

- README 提供 Node 24/Mac clone/run、升级、备份/恢复和卸载说明；Linux 当前候选执行情况以 validation.md 为准，Mac 原生仍需实际机器。
- 远程写入因身份不符暂停，不改认证；本地根提交 noreply/tree 验证保留。无 PR、合并或部署。旧 hash/cache 可能仍可见，不宣称清除。
- 已交付 bundle 保持 `c513c613`，不含后续修复/扩展；不创建新包，不把旧包当当前版本。
- 真实云连接器未实现，本轮只验证通用本地协议；Watch/Health 自动连接按用户要求延期。外部真实研究仓库未接入，仅使用虚构文件适配。
- 不做任意 Schema 自动转换、部分字段双向编辑、不可信插件 OS 沙箱、自动设备身份撤销；文档明确这些能力边界。没有附件二进制管理、自动备份周期/永久清理承诺。
- 没有降低正式判据。新增辅助测试中，错误的字段/DOM 标签按真实契约修正；原数据安全和业务断言保留。
