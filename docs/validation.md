## 分阶段边界与剩余范围

本次是阶段 B 的本地可用版本及阶段 C/D 的部分可靠性实现，**不宣称 G01–G04 全部最终完成**。完整原始需求保留在 acceptance.md，未改变验收语义。

- 真实供应商同步、设备密钥恢复/撤销、实体/字段白名单及自动上传尚未实现。现支持模块白名单的本地模拟包与可选CLI认证加密信封；浏览器/普通命令仍明文，数据存储未加密。
- Apple Watch/iPhone 真机桥接及外部研究仓库适配未接通；无自动实盘执行。
- 声明式模块可用；完整 operation/importer/dependency 声明、复杂迁移转换、可执行插件生命周期/隔离仍待实现。
- 跨Schema历史不能直接初始化空副本；测试证明安全拒绝且游标/实体回滚。可信完整备份能初始化本地隔离副本，但不替代较窄授权的迁移同步基线。
- 跨周轮换、自定义情境、位置转移模型、夏令时重复/缺失钟点消歧、周期复盘自动建议仍待扩展。
- 记录汇率但没有自动换算；资产负债快照可记录/比较，尚无完整净资产历史分析。
- 没有附件二进制管理、自动备份周期/过期策略、永久删除或私人历史清理；备份只覆盖应用管理的笔记与数据库状态。
- 没有 Mac 原生测试证据，CI 配置尚未在 GitHub 执行。开源许可证尚待决定。
- 远程根提交仍未修复；本地修复保持原 README tree，新功能为独立分支。待正确个人连接由父任务确认后，再检查 main 和精确 lease。旧 hash/cache 仍可能可见，未宣称抹除。

规则文件只在此项目生效；没有修改账户全局设置，也不宣称文档能自动切换模型。

## 本轮复现、修复与回归

最初新增的五个安全回归在原基线 **5/5失败**，实际复现同名未托管Markdown覆盖、缺表备份静默恢复、无效实体提交后才报错、移动笔记路径丢失，以及同步后来源去重状态缺失。不是仅创建测试文件。对应机制已修复，新增安全测试扩展到10例。

- Vault新笔记采用排他创建与不冲突命名；已有笔记在替换前再核对预期hash。
- 备份在数据库事务内读取逻辑表并核对正文索引。恢复先在隔离临时目录校验完整表集、实体/当前Schema、笔记路径与索引、关系及历史状态，再发布目标目录；失败不发布半成品。旧Schema历史校验可读结构/身份，尚无完整历史Schema仓库。
- 二次独立复查发现损坏conflicts JSON和cursor可漏过恢复，已加入拒绝用例与正常冲突恢复后可解决的反例。
- 来源身份/修订收据随接收操作重建；确定性来源ID和规范化摘要避免跨副本重复。同修订改内容、同操作ID改内容被拒绝，人工编辑不改原始导入收据。
- Agent凭据不能获取人工会话；错误凭据即使附有效cookie也拒绝。同步检查历史及当前关系目标的模块范围，越界整包拒绝。
- 可选AES-256-GCM信封含用途认证，测试实际加密备份恢复、同步重放、错误密钥、篡改、用途/版本拒绝、密钥权限、符号链接及从另一cwd执行CLI。测试密钥只在临时目录产生并清理，没有真实凭据。
- CLI运行/导出/恢复/密钥路径与服务端数据根路径共用仓库外检查，包含现有父目录符号链接；库级Store仍可由测试显式实例化。
