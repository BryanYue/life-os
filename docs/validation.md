## 已验证行为

- 八领域分别经 API/存储与浏览器完成创建、修改、关联、查询、复盘；重启/刷新后保留。
- 多目标普通/加班/疲劳草案保留固定块及生活预留，容量缺口可见；采纳前无计划写入，重复采纳幂等。
- 学习目标→材料→学习→知识笔记→项目输出→复盘；笔记移动后稳定 ID 关联。
- 两版 AI/量化实验保留数据、参数、代码与评价差异；英语/日语实际分钟独立，不混入计划。
- 精确金额相加与按币种分类汇总；家庭记录默认本地且同步拒绝。
- 来源重复、修订、旧来源重放；合成健康导出解析的单位/时区/来源与错误检查。A01 仅指本项目 JSON 交换格式，不是 Apple 原生 HealthKit/XML 适配或 A02 自动联动。
- HTTP 会话、Host/Origin、CSRF、伪造 actor、Agent 越权和不存在的外部执行端点被拒绝；导入的恶意文本仅作为正文。
- 双副本离线修改、断续手动交换、重复包、不同字段/Markdown行合并、同字段冲突、解决后收敛、删除与离线编辑冲突。
- 数据库提交后崩溃的笔记日志重放；外部正文保护与恢复入口；未知 frontmatter 保留，符号链接拒绝。
- 备份恢复、停用模块恢复、旧包重放、植物模块及私有声明并存、Schema 迁移失败回滚和备份恢复。
- 1280×720 桌面侧栏可滚动、390px 手机导航、备份下载、409 时未保存正文保留。

## 分阶段边界与剩余范围

本次是阶段 B 的本地可用版本及阶段 C/D 的部分可靠性实现，**不宣称 G01–G04 全部最终完成**。完整原始需求保留在 acceptance.md，未改变验收语义。

- 真实供应商同步、认证加密包、密钥恢复/撤销、实体/字段白名单及自动上传尚未实现；目前只有模块白名单的明文本地模拟包。
- Apple Watch/iPhone 真机桥接及外部研究仓库适配未接通；无自动实盘执行。
- 声明式模块可用；完整 operation/importer/dependency 声明、复杂迁移转换、可执行插件生命周期/隔离仍待实现。
- 跨周轮换、自定义情境、位置转移模型、夏令时重复/缺失钟点消歧、周期复盘自动建议仍待扩展。
- 记录汇率但没有自动换算；资产负债快照可记录/比较，尚无完整净资产历史分析。
- 没有附件二进制管理、自动备份周期/过期策略、永久删除或私人历史清理；备份只覆盖应用管理的笔记与数据库状态。
- 没有 Mac 原生测试证据，CI 配置尚未在 GitHub 执行。开源许可证尚待决定。
- 远程根提交仍未修复；本地修复保持原 README tree，新功能为独立分支。待正确个人连接由父任务确认后，再检查 main 和精确 lease。旧 hash/cache 仍可能可见，未宣称抹除。

规则文件只在此项目生效；没有修改账户全局设置，也不宣称文档能自动切换模型。
